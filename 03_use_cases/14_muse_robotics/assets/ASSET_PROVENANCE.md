# Asset provenance

All raster media in this directory is people-free. No visitor photograph, voice recording, transcript, private endpoint, credential, or event footage is included.

- `muse_robotics_hero.png`: Muse Image-generated kiosk hero depicting an illustrative Reachy Mini, an AI brain, a Franka Panda arm, and red/green/blue blocks. Source asset: `demo/kiosk/assets/booth_hero.png`. SHA-256: `82815ffa93e78a789d3180c59e75a7dd50def6724dacb244613c62efb9d9c447`.
- `connect_kiosk.png`: screenshot of the working kiosk's attract state using generated hero art and simulated-arm thumbnails; it contains no live camera frame or visitor data. Source asset: `results/kiosk/fixes/reachy_connected.png`. SHA-256: `0074eeff5c8ad613ea8bea0497290c3d05e183f5a617d1a85259b6f6fd4afafb`.
- `reachy_mini_card.png`: people-free Muse Image-generated fallback card used when the working kiosk has no fresh Reachy camera frame. Source asset: `demo/kiosk/assets/reachy_card.png`. SHA-256: `42ad5c57d8ead2d3e2aefb36f66f5f018cd7c97506ea11a933f70082046d2a56`.
